# yaksa-corpus

약사 국가고시 학습자료를 AI가 쓸 수 있는 구조로 전처리합니다.
원본은 Google Drive 에 그대로 두고 읽기만 합니다. 산출물만 여기에 만듭니다.

작업 규칙과 스키마 계약은 [AGENTS.md](AGENTS.md)에 있습니다. 에이전트는 그 문서를 먼저 읽습니다.

## 왜 이 구조인가

원본 PDF 724개 9,504쪽을 전부 열어 확인한 결과입니다.

| 텍스트 레이어 | 파일 | 쪽 | 비중 |
|---|---:|---:|---:|
| CLEAN — `pdftotext` 정상 | 170 | 1,772 | 25% |
| MOJIBAKE — 텍스트는 있는데 깨짐 | 288 | 4,055 | 커버 |
| SCAN — 텍스트 레이어 없음 | 260 | 3,584 | 커버 |

MOJIBAKE 는 HWP → Acrobat Distiller 경로에서 ToUnicode 매핑이 깨진 파일입니다.
`약물학 공부가이드`를 뽑으면 `덓ꤒ쌯 髋ꭖ ꧿썻` 처럼 나옵니다. 폰트마다 매핑이 달라 역변환은 수지가 안 맞습니다.

**렌더링은 세 부류 모두 완벽합니다.** 글리프는 멀쩡하고 인코딩만 깨졌기 때문입니다.
그래서 `렌더 → 비전 → 구조화`를 기본 경로로 쓰고, CLEAN 25%만 `pdftotext` 로 우회합니다.

중복을 걷어내면 7,155쪽입니다. 같은 기출 PDF 가 15개 과목 폴더에 복사돼 있어 2,349쪽이 중복이었습니다.

## 산출물 3층

| 층 | 내용 | 위치 |
|---|---|---|
| L0 | 인벤토리. 파일마다 과목·종류·쪽수·텍스트레이어·추출경로·SHA·중복그룹 | `data/manifest.json` |
| L1 | 원문. PDF 한 쪽당 마크다운 한 개 + 출처 프론트매터 | `l1/{sha}/p-NNNN.md` |
| L2 | 지식 객체. 문항·카드·가이드 | `l2/*.jsonl`, `l2/guide.json` |

## 실행 순서

```bash
npm run g0        # 인벤토리 (LLM 없음, 약 2분)
npm run g1 -- --type past-paper   # 기출 렌더 (LLM 없음, CPU)
npm run g4        # 플래시카드 (LLM 없음, 즉시)
npm run g2        # 공부가이드 구조화 (83쪽)
npm run g3        # 기출 문항 2,450개  ← 가치 밀도 최고
npm run verify    # 게이트 전량
npm run accuracy  # 전사 정확도 측정
npm run status    # 진행 상황
```

쪽수가 아니라 가치 순으로 자릅니다. G2+G3+G4 는 538쪽으로 전체의 7.5% 인데,
문제 검색·약점 분석·모의고사 생성이 여기까지면 다 돌아갑니다.
주교재 전량(G5)은 그 다음에 판단해도 늦지 않습니다.

```bash
npm run g5 -- --route pdftotext        # CLEAN 1,772쪽, LLM 비용 0
npm run g5 -- --type textbook          # 주교재
npm run g5 -- --subject pharmacology
```

## 재개

모든 단계가 중간에 죽어도 이어서 돕니다. 키는 `{content_sha}-{page}` 입니다.
산출물이 이미 있으면 건너뜁니다. 다시 만들려면 `--force`.

실패한 항목은 전체를 멈추지 않고 `reports/quarantine.jsonl` 에 쌓입니다.

## 검증

`npm run verify` 가 게이트를 전부 돕니다.

- 회차·교시별 문항 수 (1교시 100 / 2교시 90 / 3교시 77 / 4교시 83, 합 350)
- 선지 정확히 5개
- 정답 커버리지 100%
- 중복 id 0
- 과목 문항 구간이 원본 `00. 기출문제 안내.md` 15개와 일치
- 정답지 과목 칸으로 영역 교차검증
- 렌더 쪽수 == manifest 쪽수

정확도는 따로 잽니다. CLEAN 1,772쪽에는 `pdftotext` 라는 공짜 정답지가 있어서,
같은 쪽을 비전으로도 전사해 문자 단위로 비교합니다(`npm run accuracy`).
거기서 나온 오차율이 정답지가 없는 5,383쪽의 신뢰도 추정치입니다.
**이 수치 없이 "추출 완료" 라고 보고하지 않습니다.**

## 경계

**이 저장소는 코드만 공개합니다. 학습자료와 추출 결과는 공개하지 않습니다.**

| 대상 | 위치 | 공개 |
|---|---|---|
| 파이프라인 코드·스키마·리포트 | 이 저장소 | 공개 |
| 원본 학습자료 | `$SOURCE_ROOT` (개인 드라이브) | 비공개 |
| 인벤토리·렌더·L1·L2 | `data/` `render/` `l1/` `l2/` | 비공개 (gitignore) |

원본은 각 대학 정리본·국시원 기출 등 저작물이라 재배포하지 않습니다.
자료 경로도 코드에 넣지 않고 `.env` 의 `SOURCE_ROOT` 로만 받습니다.

`npm run privacy-check` 로 추적 파일에 자료 경로·개인정보·추출물이 섞였는지 검사합니다.

## 준비

```bash
cp .env.example .env
```

`LLM_API_KEY` 를 채웁니다. G0·G1·G4 는 키 없이도 돕니다.
poppler(`pdftotext`, `pdftoppm`, `pdfinfo`)가 PATH 에 있거나 `POPPLER_BIN` 이 필요합니다.
